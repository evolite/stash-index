# stash-index

GitHub mirror of my Stash plugin index.

- **Source of truth:** https://surging9143.codeberg.page/index.yml (updated by each plugin's release workflow)
- **This mirror:** https://evolite.github.io/stash-index/index.yml, synced from Codeberg every 15 minutes by `.github/workflows/sync.yml`

Add either URL as a plugin source in Stash. Don't edit `index.yml` here; changes are overwritten by the sync.
